# DigiTwin CDN

This branch is used exclusively for **CDN (Content Delivery Network)** purposes.

## Description
This repository/branch serves as a storage and delivery point for static assets. By utilizing this dedicated space, we ensure high availability and low-latency access to resources through CDN integration.

## Important Note
- **CDN Only**: Do not use this branch for active development or application logic.
- **Asset Focused**: This branch is optimized for hosting frames, images, and other static content.
